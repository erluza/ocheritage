KEEP THE PORTS ALIVE

A friendly reminder from the OptiCraft Heritage community.

If you enjoy a port, remind its developer to keep the download links updated to the latest version, so everyone can find the newest builds.

We also recommend always asking developers for the source code of their projects. Sharing code keeps ports alive, portable and easier to maintain.

Good links and shared source code keep this site useful for everyone. Thank you for supporting the developers!
